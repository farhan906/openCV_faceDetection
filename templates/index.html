Welcome to the Face Recognition System

Use the navigation menu to add a person or start face recognition.

Using facial recognition technology, this real-time attendance monitoring system is intended to automate the process of recording attendance. This project records live video feeds, finds faces inside the frames, then compares those faces to a database of people who are already defined. The system makes use of OpenCV for video capture, the haarcascade classifier for face detection and DeepFace's FaceNet512 model for effective face encoding. The system effectively matches the identified faces with the stored data by utilising cosine_similarity, offering a quick and effective way to recognise faces in real time.
